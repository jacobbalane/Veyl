# If something isn't working

First release coming soon. Detailed help will be added as each behavior is implemented and
checked on devices. [UI copy](ui-copy.md) defines the planned messages.

Phone mode will need the same local network on both devices. Guest networks and client
isolation may block discovery; Add by address is the planned fallback. Other Android apps can
block playback capture; the Veyl player and test sound are planned alternatives.

The phone's screen must stay on while listening. Device-specific battery and picture-in-picture
advice will follow the listening milestone's checks. Use [progress](progress.md) for build limits.
